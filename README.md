# training_diary — щоденник тренувань

Наскрізний проєкт з дисципліни «Програмування мовою Dart», варіант 7
«Щоденник тренувань».

Автор: Зьома Гліб Ярославович, група ПЗПІ-23-10.

## Лабораторна робота 1. Функції та обробка колекцій

Консольна програма розбирає вбудований набір записів щоденника, відкидає
пошкоджені рядки з поясненням причини, перевіряє діапазони значень і формує
текстовий звіт: хронологію, топ за дистанцією, темп, групування за видами
активності й підсумкові значення. Класи навмисно не використовуються.

### Запуск

```bash
dart pub get
dart run
dart analyze
dart test
```
